# 身材管理

个人减脂期间的饮食、运动和体重记录，支持在两台电脑之间通过 Git 同步。

## 文件

- [饮食与运动日志.md](饮食与运动日志.md)：基础信息、每日餐食及估算、训练、体重、日报和周报。
- 餐食照片目前不保存在仓库中；另一台电脑可以阅读文字记录，但不能依赖原电脑的微信缓存图片。

## 记录方式

把餐食照片及份量、剩余情况、加餐饮料、运动、步数、睡眠发给当前电脑上的助手，并让助手更新日志。晨重建议在起床排尿后、进食饮水前、相似穿着及同一台秤条件下测量。不同秤的数据需注明设备，避免直接混作可比晨重。

- 日报：北京时间次日中午12:00汇总前一自然日，纳入次日上午补充的训练情况。
- 周报：目前设置为北京时间周日22:00汇总本周；之后补充的周日数据需补入周报。
- 照片热量和蛋白质均为估算，未知数据不补零；按实际发生日期记录，避免重复。

## 两台电脑同步

另一台电脑首次使用（先安装 Git，在希望存放项目的父目录执行）：

```powershell
git clone https://github.com/yuanwei020626-commits/body-manage.git
cd body-manage
```

每次开始记录前，在仓库目录执行：

```powershell
git pull --ff-only
```

更新完记录后，检查差异并提交推送：

```powershell
git diff
git add -- README.md 饮食与运动日志.md
git commit -m "更新饮食与运动记录"
git push
```

请先在一台电脑提交并推送，再换另一台电脑拉取和编辑，尽量不要同时修改同一日志。若拉取提示本地有未提交修改或分支分叉，先保留本地内容，再让助手比较和合并；不要使用强制推送或硬重置覆盖记录。

## 自动汇总与隐私

Git 只同步已提交的文件，不会同步聊天历史、微信缓存照片、登录凭据或 Codex 自动化设置。当前日报和周报自动化关联原电脑的聊天与本地路径 `D:\身材管理\饮食与运动日志.md`，并不会因为克隆仓库而自动在另一台电脑运行。自动化写入的报告也需要提交推送才能同步。需要迁移时应调整现有自动化的运行位置和路径，避免重复创建。

开始新聊天时，请让助手先读取本 README 和日志，再继续记录。仓库包含体重、腰围等个人健康信息；能看到仓库的人也能看到这些记录，后续删除文件不等于清除 Git 历史。
